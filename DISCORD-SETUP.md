# Настройка Discord Rich Presence для Sunspire

## 1. Включите показ активности в Discord

Discord → **Настройки пользователя** → **Конфиденциальность активности**
(в новых версиях: **Activity Privacy**) → включите **«Показывать текущую игру/активность»**
(Share your detected activities with others).

Без этого Discord не показывает чужим пользователям никакую активность, даже если
лаунчер всё отправляет.

**Режим разработчика** (Настройки → **Расширенные** → **Режим разработчика**) нужен
только для копирования ID пользователей/серверов. Для Rich Presence он не обязателен.

## 2. Проверьте приложение Sunspire

1. Откройте <https://discord.com/developers/applications>.
2. Выберите приложение **Sunspire** (ID `1570081050732793906`).
3. **General Information** → **App Icon** → загрузите `logo.png` (1024×1024).
   Это иконка приложения (маленькая иконка в углу карточки).
4. **Rich Presence** → **Assets** → **Add Image(s)** → выберите `logo.png`.
5. После загрузки задайте **Asset Key** ровно `logo` (строчными буквами).
   Если ключ другой, переименуйте его в `logo`.
6. Нажмите **Save Changes** и подождите 2–5 минут. Discord кэширует ассеты.

Именно ключ `logo` использует лаунчер:
`large_image = "logo"`, `large_text = "Sunspire Minecraft Launcher"`.

## 3. Настройки лаунчера

Откройте **Настройки → Интерфейс**:

- **DISCORD RICH PRESENCE** — включено.
- **DISCORD APPLICATION ID** — можно оставить пустым (тогда используется
  `1570081050732793906`) или вставить `1570081050732793906` вручную.
- Нажмите **ОТКРЫТЬ LOGO.PNG**, если нужен файл для загрузки в Discord.

## 4. Перезапуск

1. Полностью закройте старые копии лаунчера: трей → **Выход**.
2. Запустите новую сборку Sunspire (не старый Electron/`Start-Sunspy`).
3. Убедитесь, что Discord Desktop запущен и вы вошли в аккаунт.
4. Через несколько секунд в профиле Discord появится:
   - **Играет в Sunspire**
   - **В лаунчере** / **В игре**
   - **Одиночная игра** или **Сервер: <адрес>**
   - большая картинка — `logo` из Rich Presence Assets.

## 5. Важно про визуализатор

Страница **Rich Presence → Visualizer** в Developer Portal — это **не** живой статус
лаунчера. Она показывает пример карточки с полями, которые вы вводите вручную.
Пустой **large Image Key** там — нормально, пока вы не выберете ассет.

Реальный статус смотрите в профиле Discord (или с другого аккаунта).

## 6. Если не отображается

- Discord Desktop должен быть запущен; Web-версия Rich Presence не поддерживает.
- В Discord включён показ активности (пункт 1).
- Запущена именно новая Rust-сборка, а не старый лаунчер.
- В лаунчере включён **DISCORD RICH PRESENCE**.
- В приложении Discord есть ассет с ключом `logo` (пункт 2).
- Перезапустите Discord после загрузки ассета (иногда помогает Ctrl+R в Discord).
- Подождите 20–30 секунд: Discord синхронизирует статус не мгновенно.
- Если в статусе виден другой game page (например, Overwatch/Minecraft), значит
  используется чужой Client ID. Вбейте `1570081050732793906` в поле App ID.
